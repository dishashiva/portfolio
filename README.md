# Disha S — Portfolio

Personal portfolio website built with Astro, React, and Tailwind CSS. It presents selected projects, skills, experience, and contact links, with project demos and a research paper linked from the site.

## Development

Requirements: Node.js 22.12 or later and npm.

```bash
npm install
npm run dev
```

Astro serves the site locally at `http://localhost:4321`.

## Commands

| Command | Purpose |
|---|---|
| `npm run dev` | Start the local development server |
| `npm run build` | Build the static site into `dist/` |
| `npm run preview` | Preview the production build locally |

## Structure

- `src/pages/` — home, projects, skills, and 404 pages
- `src/components/` — shared navigation, project, skill, and experience components
- `src/layouts/` — shared page layout
- `public/` — static assets and the linked research paper
